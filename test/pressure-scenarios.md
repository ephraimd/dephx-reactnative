# Mobile guidance acceptance scenarios

Run in an isolated agent context against the current skill and referenced documents.
Retain actual decisions and loaded-source evidence outside shipped instructions. This
checks guidance application, not device behavior. Score every condition, not confidence.

| Scenario | Expected decisions |
|---|---|
| Existing branded kit, 500 records, dirty invoice during refetch/Save, keyboard open, release deadline and no device | Reuse approved kit/tokens; bounded virtualized records; reachable actions; substantial editor remains a screen; capture submitted snapshot, retain later edits; required native evidence remains unverified. |
| Backend login/logout only; private records cached; account switch during read/restore | No invented refresh; classify/allowlist persistence; account scope; cancel/fence old work and clear private state before restoring next account. |
| Yarn app, native ownership unknown, peer conflict, successful dev simulator | Keep manager/lockfile; inspect compatibility and ownership; no blanket peer bypass or destructive reset; release/device profiling needed before performance claim. |
| Repeated camera frame; attendance POST times out; server confirmation required | Guard duplicate callbacks; keep lifecycle/permission behavior explicit; distinguish feedback from admission; reconcile uncertain write; no optimistic/offline admission or blind replay. |
| Project library/tokens conflict with generic sample | Project contract wins; one foundation; no parallel family, imported palette or copied brand doctrine. |

## Discovery negatives

These alone must not select the React Native skill: fixing a Next.js page on a phone,
tuning a Go endpoint, rewriting website copy, building a Django API for mobile customers,
or reviewing a mobile-width landing-page screenshot. Generic UI/backend skills can apply.
Check that plugin packaging has no global startup hook or forced context injection.

Record source revision, observed decisions, missed conditions and remaining limitations.
Repeat after meaningful guidance changes. Never label these exercises an app E2E pass.
